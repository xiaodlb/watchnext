# Together Tonight Watchlist

Design a responsive frontend prototype for WatchNext, a private shared watchlist.

Create screens for:

- Sign in and create account

- Group watchlist, with All / Added by me filters

- Add a movie, series, anime, or YouTube video

- Search results with poster or thumbnail previews

- Title details, progress, rating, and notes

- “Pick for me” with available time and mood

Use realistic sample data and make the screens clickable. Use mock data only: no Supabase, backend, authentication service, or real API calls. Keep the interface friendly, clear, and usable on mobile and desktop.
