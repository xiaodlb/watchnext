## Bounded implementation

Extend the same mounted `/mock` typed service with library list/archive/detail/edit/remove-own/restore operations and small internal list/detail/edit/archive views. Seed explicit Movie, Series, Anime and YouTube records, a joint contribution, inactive attribution, one archived item and nullable expired provider fields across existing account and legacy groups. Link seeded membership contribution/history references to these actual records without deleting or reassigning them. History is readonly attributed data here; editing progress/ratings/notes belongs to #59. New manual/provider saves and duplicate confirmation belong to #58; show an honest unavailable Add destination rather than a working-looking stub.

Every operation rechecks selected group, active account membership or legacy access, captured context and membership epoch. Legitimate legacy browsing needs no selected profile; own writes require a selected same-group profile. Account own-member identity derives from the current account membership. A group creator has no extra metadata privilege. Removed membership, foreign/missing title, stale group/profile context and archived-write attempts yield safe service errors, never authority from caller IDs.

## Evidence and scope boundary

Capture current title revision/context in edit/removal/restore intent and recheck before commit. Clearing a stale view must not erase a retained unsaved draft without explanation.

Represent due provider fields with a readonly expired fixture projection: unavailable fields and cover fallbacks, independently authored corrections retained. Changing the draft cancels pending work and clears an obsolete identity confirmation. Cancel/return-to-draft writes no metadata. Missing NULL type can be filled only with compatible retained structure/history and confirmation. Changed fields become authored corrections, unchanged field origins remain unchanged. Stable IDs/provider/creation identity, contribution records and history are not overwritten. Removal marks only the current contribution inactive in the synthetic store; restoration reuses it where present, preserving opaque references/history.
