## Goal

Connect the complete accepted graded frontend to the real typed same-origin `/v1` HTTP services over process memory. Every inventory operation must work through the actual visible application and shared product views, while the explicit synthetic mock mode and existing normal-data application remain isolated and usable; this is not durable SQLite/Prisma integration.

## Acceptance criteria

- [ ] **One visible product frontend/two real adapters:** a clearly linked HTTP-memory entry uses the centralized typed HTTP adapter for every A/G/L/W/M/P/K domain read/write and preserves U01–U06 interactions, with the existing inventory-to-operation map checked against actual UI calls. Reuse/extract the accepted domain views rather than build a hidden duplicate app or one successful demo screen. `/mock` remains explicitly selectable with its accepted synthetic semantics. HTTP mode has no local mock write/read fallback, fixture-login shortcuts, direct Server Action/SQL calls or ignored/unimplemented controls. Its notice says real sessions/process-memory data lost on server restart; it does not falsely label real HTTP as fake authentication or durable storage.
- [ ] **Complete live-identity/library UI journey:** actual register/login/logout/recovery/private-code views, account create/invite/explicit join/multiple-group switch/creator remove-rotate and separate legacy profile flows consume real cookies and server context. All/Mine/archive/details/manual/provider Add/edit/remove/restore show actual same-entry contributors/inactive status/history and live permissions; no account profile impersonation/legacy claiming or creator metadata override. Internal navigation/back/reload revalidates current authority, discards stale cross-group views and preserves same-process memory records/session semantics. Group/member removal, recovery/session expiry and away/back context changes invalidate pending forms/reviews/cycles rather than repaint private old state.
- [ ] **Faithful forms/provider/personal/picker behavior:** serialize UI text into the declared HTTP DTOs with strict client validation and runtime-safe response decoding, including genre/mood arrays, nullable URLs, integer coordinates/stopped-at/rating/budget and flags. Preserve Unknown versus Not started, independent completion/clear, 1–10 ratings and plain-text 2000-code-point notes, readonly archive/history and own-member writes. Provider title/link/candidate/paging yields clean automatic editable fill, current dirty Replace/Keep consent, manual mood/runtime/numbering gates and correction-safe refresh/unavailable states. Full/typical runtime, selected viewers, default-off rewatches, exact eligibility/fallback labels, no-repeat same-tier cycle/exhaustion/restart and logical retry match the accepted rules; no UI filter/feedback changes ranking or progress automatically.
- [ ] **Transport/private/error state correctness:** known same-origin methods/paths send real credentials and current stale-intent revisions, never mock scenario/outcome/time/reset values or caller-provided actor authority. Handle validation/field errors, anonymous/access denial, stale/conflict/expired handle, non-JSON/malformed/network failures and retry without inventing success or silently falling back. Pending/duplicate prevention, preserved nonsecret drafts, secret clearing/once-only copy/manual fallback/departure erasure, safe previews/links and typing/latest-response focus guards remain functional. Abort discards late results locally but cannot claim to roll back committed HTTP mutations; lost recovery/invite replies have no retrieval backdoor, and picker retries reuse logical intent without extra advancement.
- [ ] **Actual all-operation app evidence:** a portable supported current-source production-browser command runs real UI journeys at 375px/1280px with keyboard/visible focus/announcements/no overflow, real two-account cookie contexts and separate legacy access. Cover all 40 inventory IDs (M06 via real expiry effects) and six U groups, every declared personal clear/undo/confirmation/retry path and server request mapping. Through forms create data, joint contributions, group switches, provider reviews, own history/feedback and picker results, then verify real detail/list/history readback and unauthorized/stale denials. Substitute only outbound provider/image fixtures at the transport boundary; never stub app `/v1` responses, real cookies, memory repository writes or native crypto to make a screen pass. Retain safe screenshots/request summaries mapping operations, not HAR/cookies/secret responses or fabricated human testing.
- [ ] **Reload/restart/isolation evidence:** real UI reload within the same owned server retains its memory account/group/title/history; an owned server stop/start loses accounts/sessions/titles/reviews/cycles, rejects old cookies/handles, clears stale private views and offers an honest fresh-registration/access path. There is no automatic SQLite import or durable-recommendation claim. Explicit mock mode still has per-instance/reset lifetime; normal production/query entry stays unchanged, and unconfigured HTTP memory mode fails visibly without fallback. Configured/default DB paths stay absent, neighboring normal/demo/file sentinels unchanged, provider secrets unused and owned processes/temp files cleaned. Actual adapter/UI/contract/full-suite/typecheck/build/mock/HTTP-memory checks are recorded with inherited E2E limitations rather than hidden retries or weakened assertions.
